코드로 못 답한 잔여분 4가지 — 나머지는 코드로 확정돼 안건에서 내려도 됨

1. wrbank DB 속성 실값 — 7필드 각각 실제 required/dataType/연산자, 화면(1)·행동(2) DS별 required 마킹, accessTime의 dataType·단위. (코드는 메커니즘만, 실값은 데이터)

2. field-values value-name 타겟의 name 검색 커버 — 하위 MyBatis mapper 동작. (agent-api 레이어 밖)

3. 콘솔 "정상 기본조건" 구성 사례 — 콘솔이 어떤 필드를 어떤 연산자/값으로 자동으로 채우는지(서버 코드엔 없음).

4. 배포 버전 정합 — 넷스루 운영망 agent-api가 a9e59bda와 동일 계약인지.
